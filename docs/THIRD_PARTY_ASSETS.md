# Third-party assets and licenses

What ships in the game that the studio did not write, and what proof of its license is IN THE REPOSITORY. Written 2026-10-12 from the files themselves; **nothing here is
assumed**: where the repository holds no license evidence the row says UNVERIFIED and the owner has to supply it (purchase receipt, license page, author statement).
A public release or a Steam submission must not go out with an UNVERIFIED row that matters to it.

Evidence levels: **FILE** = a license file sits next to the asset; **AUTHOR PAGE** = the owner saw the author's page state the license, recorded here and in the
asset's own notice; **GENERATED** = produced by this repository's own tool (no third party); **OWNER** = created by or for the studio; **UNVERIFIED** = none found.

## What this means

- Free to ship now (evidence in repo): the glyph library (CC0 per the author's page, copy still to be stored), both fonts, both Kenney packs, the generated sounds, the studio's
  own art.
- Needs the owner before a public release or a Steam page: every **UNVERIFIED** row. Supply, per row, the source, the license text or receipt, and any required credit line;
  this page then moves the row to Verified, and `NOTICE`/credits text can be added to the game's About screen if a license requires one.
- Candidates for removal instead of verification (no scene uses them, saves ~300 MB in the Windows package): the AllSkyFree skyboxes, the Andromeda video, the
  night-sky texture.
- Nothing was removed or replaced by this audit.

## How to add an asset

Put the license file or a short `NOTICE.md` next to it, add a row here with the evidence level, and keep imports reproducible when a tool can do it (see
`tools/import_glyph_library.py` and `assets/ui/glyphs/NOTICE.md`).
